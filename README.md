# 教學影片防換頁暫停 (選單控制）

---

## 📌 用途說明

某些線上課程、數位學習平台（如 TronClass、各大學 eSchool）會把影片設定成「在**切換分頁、最小化視窗或失焦**時，自動暫停播放」，本腳本能讓那些影片在切換頁面後繼續播放。

本腳本採用動態白名單與圖形化管理介面，讓使用者可自行針對需要的網站一鍵啟用防暫停與保持視窗活躍機制。

⚠️ 使用前請先詳閱下方免責聲明 ⚠️

---

## 📥 安裝說明

1. 確保您的瀏覽器已安裝 **Tampermonkey (篡改猴)** 擴充功能。
2. 點擊 [👉 安裝「教學影片防換頁暫停」腳本](https://update.greasyfork.org/scripts/604108/%E6%95%99%E5%AD%B8%E5%BD%B1%E7%89%87%E9%98%B2%E6%8F%9B%E9%A0%81%E6%9A%AB%E5%81%9C%20%28%E9%81%B8%E5%96%AE%E6%8E%A7%E5%88%B6%EF%BC%89.user.js) 直接觸發安裝。
3. 亦可前往 Greasy Fork 腳本頁面，點擊頁面上的 **「安裝此腳本 (Install this script)」** 按鈕完成安裝。

---

## 🎮 操作說明

1. **開啟設定面板**：
   * 進入任意網頁後，點擊瀏覽器右上角的 **Tampermonkey (篡改猴)** 圖示。
   * 在選單中點擊 **「⚙️ 開啟防暫停設定面板」**。
2. **新增與管理網域**：
   * 點擊面板內的 **「+ 一鍵填入當前網站」**，或手動輸入目標網域（例如 `elearn2.fju.edu.tw`）。
   * 點擊 **「新增」** 後，即可在下方列表中看到該網域。
   * 您可以隨時透過列表中的按鈕切換「啟用/停用」，或點擊「刪除」移除網域。
3. **生效方式**：新增並確認啟用後，**重新整理網頁 (F5)** 即可讓防暫停機制在該網站生效。

## ⚙️ 原理介紹

本腳本透過以下核心機制，盡可能維持分頁與影片的播放狀態：

- **攔截 `visibilitychange` 事件**：在捕獲階段攔截分頁可見性變更事件，阻止事件繼續傳遞至後續監聽器，降低網站透過此事件偵測分頁切換的機會。
- **覆寫 `document.hidden` 與 `document.visibilityState`**：強制讓網頁讀取時分別取得 `false` 與 `visible`，使網站誤以為分頁始終處於前景可見狀態。
- **攔截 `blur` 與 `focus` 事件**：在捕獲階段攔截視窗失焦與取得焦點事件，並在失焦時主動呼叫 `window.focus()`，盡可能降低網站因視窗失焦而暫停影片的機會。
- **偽造 `document.hasFocus`**：將此方法覆寫為固定回傳 `true`，使網站讀取時認為目前頁面始終具有焦點。
- **定期主動聚焦**：每隔 10 秒呼叫一次 `window.focus()`，嘗試重新取得視窗焦點，以輔助維持背景播放。

**注意事項：** 上述機制主要針對網站前端的分頁可見性與焦點偵測，無法直接控制瀏覽器底層的背景分頁凍結、計時器節流或系統資源管理。因此，實際效果仍可能因瀏覽器、作業系統及網站播放器的實作方式而有所不同。
